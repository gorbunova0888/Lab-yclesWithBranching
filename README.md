## Цель работы
Освоение базового синтаксиса C++ и математических вычислений на примере расчета числа Грасгофа (Gr) и числа Нуссельта (Nu) для конвективного теплообмена.

## Описание
Программа рассчитывает число Грасгофа и число Нуссельта для пакета вертикально расположенных труб водяного отопления. 
В зависимости от значения числа Грасгофа (больше или меньше \(10^9\)), программа автоматически выбирает соответствующую эмпирическую формулу для расчета числа Нуссельта.

## Входные данные
Пользователь вводит с клавиатуры:
- Количество итераций (диаметров труб) — целое число.
- Температуру газа (\(t_r\)) — в градусах Цельсия.
- Температуру воды (\(t_v\)) — в градусах Цельсия.
- Вязкость газа (\(\vartheta\)) — в \(см^2/с\).
- Диаметр трубы (\(d\)) — в метрах (для каждой итерации).

## Выходные данные
Программа выводит в консоль таблицу со следующими значениями для каждого введенного диаметра:
- Диаметр трубы (м).
- Число Грасгофа (Gr) — безразмерная величина.
- Число Нуссельта (Nu) — безразмерная величина.

*Ожидаемые результаты для \(t_r = 500^\circ C\), \(t_v = 15^\circ C\) и \(\vartheta = 0.15\ см^2/с\):*
- \(d = 0.1\ м \rightarrow Gr = 73423613.0,\ Nu = 40.8\)
- \(d = 0.3\ м \rightarrow Gr = 1982437552.0,\ Nu = 269.2\)

## Как запустить
1. Открыть файл решения `.sln` (или сам файл `.cpp`) в Visual Studio.
2. Собрать проект (Build -> Build Solution).
3. Запустить программу без отладки: нажать `Ctrl + F5` или выбрать в меню "Отладка" -> "Запуск без отладки".
